This is an add-on to the existing Manager Dashboard and Field Worker App.

Do not rebuild the whole app.
Do not change the core architecture.
Keep the existing shared database, backend API, Manager Dashboard, and Field Worker App.

Feature goal:
When a field worker uploads a batch of tree photos, the system should analyze each image for structured visual quality and grove-health indicators. These results should be saved as draft AI-assisted observations, reviewed by the manager, and connected to trees, field visits, monitoring tasks, harvest events, and heritage-rule evidence.

Important:
The system must not claim final diagnosis from photos.
Use cautious language:
- visible stress signal
- possible pruning need
- possible drought stress
- possible pest/damage sign
- needs field verification
- low-confidence image
Do not say:
- disease confirmed
- pest confirmed
- tree is dying
- exact yield predicted

This feature should support both:
1. Monitoring Mode
Used throughout the year for tree health, pruning, drought, pest signs, terrace/soil/root exposure, and general condition tracking.

2. Harvest Mode
Used during harvest season for pre-harvest tree photos and optional box photo analysis.

Vision model instruction:
Analyze only what is visible in the image.
Do not infer exact disease, pest species, yield, age, or oil quality.
Do not claim certainty.
Use cautious language.
If the photo is unclear, say so.
Return valid JSON only.

Rule evidence:
